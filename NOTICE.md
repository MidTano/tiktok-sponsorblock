The audio fingerprinting, matcher, snapshot format and server were first written for the
**Skip ads by sound** feature of Metra, a set of TikTok patches built on
[icysymmetra/tiktok-patches-for-morphe](https://github.com/icysymmetra/tiktok-patches-for-morphe)
(GPL-3.0). They were moved here so other mods can share them.

The landmark method follows Avery Li-Chun Wang, *An Industrial-Strength Audio Search
Algorithm* (ISMIR 2003). No code from any Shazam implementation is used.
